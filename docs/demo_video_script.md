# Aura+ : 3-Minute Demonstration Video Script

> **Target Duration:** 2 minutes 45 seconds (Under the 3-minute strict limit).  
> **Platform:** YouTube or Vimeo (Public, in English).  
> **Submission Track:** Alexa+ Track ($25K) + AWS Builder Mini-Challenge ($5K).

---

### Video Structure & Timeline

#### [0:00 - 0:30] Introduction & The Problem
- **Visual:** Full-screen screen capture of Aura+ web UI with the ambient glowing Alexa+ orb.
- **Narration:**
  > *"Hi everyone, this is Aura+, an autonomous ambient concierge built for Alexa+ and powered by AWS Bedrock and the Model Context Protocol. Traditional voice assistants are reactive: they answer single questions or set timers. But real life requires multi-service orchestration across household memory, culinary planning, smart home environments, and purchasing. Today, I'm going to show you how Aura+ handles a complex real-world scenario autonomously."*

#### [0:30 - 1:15] The Grand Slam Showcase (Multi-Agent Orchestration)
- **Visual:** Click the 🌟 **"Family Weekend Prep"** 1-click showcase button (or speak into the mic: *"My parents are visiting this Friday evening for dinner and staying the weekend. Prepare the house, plan a vegetarian Italian dinner with wine pairings, check dietary restrictions from past notes, order missing groceries via Amazon Cart, set the thermostat and ambient lighting schedule, and block my calendar for Saturday morning family brunch."*).
- **Narration:**
  > *"Notice what happens instantly. Alexa+ decompresses this high-level goal into an AWS AgentCore DAG. On the right, the live Agent Brain trace streams in real time: Bedrock decomposes the goal, queries our persistent household memory, and discovers that Mom has a strict shellfish allergy and gluten sensitivity, while Dad loves Tuscan Chianti."*

#### [1:15 - 1:50] Generative UI & Interactive MCP Apps
- **Visual:** Scroll down to show the **Recipe Carousel** and the **Amazon Fresh Checkout Card**.
- **Narration:**
  > *"Instead of a wall of text, Aura+ emits interactive MCP Apps directly to the Alexa+ screen. First, an interactive multi-course recipe carousel featuring 100% gluten-free and shellfish-free Penne all'Arrabbiata paired with Dad's favorite Chianti Classico. Second, it autonomously searched Amazon Fresh inventory, verified certified gluten-free products, and compiled an itemized grocery cart totaling $62.24."*

#### [1:50 - 2:20] Financial Guardrails & Smart Ambiance
- **Visual:** Click **"Approve & Place Order"** on the Amazon Fresh card (it animates to green: *"Order Confirmed AMZ-FRESH-992-88120"*), then show the Ambiance card and adjust the temperature slider from 71°F to 72°F.
- **Narration:**
  > *"Because financial safety is critical, Aura+ features a Human-in-the-Loop guardrail. With one tap, I approve the order, scheduling Friday delivery. Below that, our Smart Ambiance Skill has scheduled the 'Tuscan Sunset' scene for Friday at 6:30 PM: 2700K amber candlelight glow, thermostat set to 71 degrees, and acoustic dinner jazz queued on Amazon Music. Sliders update the connected home in real time."*

#### [2:20 - 2:45] Technical Architecture & Wrap-up
- **Visual:** Switch the right sidebar tab to **"Memory & Devices"** to show the persistent memory profile, connected Echo Show, Fire TV, and Ring devices, then highlight the MCP 2025-11-25 Streamable HTTP status.
- **Narration:**
  > *"Under the hood, Aura+ runs a self-hosted Model Context Protocol server conforming to the 2025-11-25 Streamable HTTP specification, integrated with AWS Bedrock Converse API and AgentCore. Our code is 100% open source under the MIT license, includes 10/10 automated tests, and full friction logs for the Amazon engineering team. Thank you for watching!"*
