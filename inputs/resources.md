- **AWS Builder Center:** `builder.aws.com` (Learning hub, tutorials on Bedrock, AgentCore, Kiro)

## Track Specific Resources

### Fire TV & Vega OS
- **Docs:** Fire TV documentation, Vega developer forum, Fire Devices & Appstore forum.
- **Starters:**
  - `react-native-multi-tv-app-sample`: Vega, Android TV, Apple TV, web (drawer nav, grid, hero, video player).
  - `react-native-multi-tv-helloworld`: minimal single-codebase starter.
  - `hello-world-fire-tv-react-native`: 5-minute RN hello world.
  - `vega-video-sample`: W3C media player, focus management, live TV, IAP, content launcher.
  - `vega-sports-app`: themeable custom content app with catalog and service integration.
  - `vega-audio-sample`: music player with album, track, search, library, settings.
  - `vega-tv-interfaces-sample`: TV UI patterns for focus, i18n, navigation, scrolling.
  - `hello-world-fire-tv`: native Kotlin / Jetpack Compose path.
- **Reference:** Callstack's "The Ultimate Guide to React Native TV Development".

### Alexa+
- **Docs:** Model Context Protocol (MCP) spec (`modelcontextprotocol.io/docs/latest/getting-started/intro`).
- **Standard:** MCP spec version 2025-11-25 or later over Streamable HTTP.
- **Agent Skills:** Agent Skills standard for Alexa+.
- **Alternative:** Simulated Alexa+ experience in a web app with agentic tools.

### Bee (Wearable AI)
- **Docs:** `docs.bee.computer` (CLI, MCP server, Bee Skill, API).
- **CLI:** `bee-cli` (command-line client for accessing and exporting Bee data).
- **Skill:** `bee-skill` (for connecting AI agents to Bee context).
- **Data requirement:** Must connect to live data recorded/processed through Bee device or Apple Watch with Bee software.

### Ring
- **Portal:** `developer.ring.com` (free account & API access).
- **Docs & Reference:** Getting started guide, Ring API reference (auth, endpoints, webhooks, rate limits, SDKs), UX design guide.
- **Sample:** `ring-api-helloworld`.
- **Hardware note:** Physical device NOT required; Ring simulator is fully supported.
