4. Complete all required fields on the submission page.

### Project Requirements
- Must build or significantly update working applications using Amazon developer tools into one of the Primary Tracks.
- **Primary Tracks:**
  - **Fire TV:** Launch a demo-ready app that works on Fire OS or Vega OS. Priority categories: AI-enhanced viewing, sports, fitness, family entertainment, multi-modal UX, and computer vision.
  - **Alexa+:** Build a working Agent Skill or a self-hosted MCP server, implementing MCP spec version (minimum acceptable version is 2025-11-25) over Streamable HTTP. Optionally, simulate the Alexa+ experience in a web app using agentic tools.
  - **Bee (Wearable AI):** Connect to data recorded and processed through a Bee device or Apple Watch running Bee software, using Bee's CLI, MCP, or Agent Skills. Must deliver value to a user. Priority use cases: education, developer experience, and personal productivity.
  - **Ring:** Working app or new feature utilizing Ring APIs, SDKs, simulators, or devices (simulator or actual device). Priority categories: access control, business systems, IoT home automation, accessibility, caretaking.
- **Mini Challenges:**
  - **AWS Builder:** Primary track project incorporating AWS services (Amazon Bedrock, AgentCore, Strands SDK, Kiro Crew, SageMaker, etc.) with documented integrations. (Kiro Crew qualifies on its own as a dev tool).
  - **Open Source:** Create a new open-source project or contribute to existing public repo during hackathon window alongside primary track submission. (Requires contribution URL, project repo URL, GitHub username, description of what you did, how it works, why it matters).
- **Functionality & Platform:** Code repo must include clear setup/run instructions; demonstrated working in video.
- **Open Source Repository:** Public GitHub repo with visible open source license in the About section. For Alexa+, Bee, and Ring: code must actually import and call the track technology at runtime. Fire TV is exempt from runtime hook requirement as long as video shows it running on device/simulator.
- **Video:** Under 3 minutes on YouTube/Vimeo, public, in English.
- **Product Feedback:** Must answer 5 specific feedback questions on every tool/API/SDK used.
- **Bonus Opportunity (Friction Logs):** Optional friction log entries can earn up to a **10% judging bonus**.

## 6. Judges & Criteria
- **Stage One:** Pass/Fail baseline viability.
- **Stage Two:** 4 equally weighted criteria:
  1. **Tech Implementation:** Effective use of required APIs, SDKs, or device capabilities.
  2. **Design:** Complete, coherent product experience; intuitive interaction model for target device/platform.
  3. **Potential Impact:** Credible, specific case for solving customer needs; realistic audience beyond hackathon.
  4. **Quality of the Idea:** Creative and imaginative vs obvious.
     - *Fire TV Creative:* AI-enhanced viewing that adapts to household patterns, CV fitness app using TV camera, multi-modal UX combining voice + D-pad + visual in single flow.
     - *Alexa+ Creative:* Agentic workflow that orchestrates across services autonomously, context-aware add-on across sessions, purchasing capabilities, media support (cards, carousels), MCP Apps, Agent Skills.
     - *Bee Creative:* Cross-device orchestration (Bee + Echo + Fire TV), ambient context capture informing productivity, novel education coaching on-wrist, advance use of facts/insights, real-time functionality, synced insights.
     - *Ring Creative:* Non-security use case (accessibility aid, caretaking monitoring, package management), business system integration, multi-camera pipeline, event-based triggers.
     - *AWS Builder Creative:* Multi-service pipeline (Bedrock + AgentCore + Strands), agentic architecture with Claude/Kiro.
     - *Open Source Creative:* Meaningful feature addition with tests, bug fix unblocking developers, new integration pattern (e.g. Vega support to React Native library).
- **Bonus:** Up to 10% bonus from Friction Log entries assessed by internal team.
- **Tie Breaking:** Evaluated in order of criteria (Tech Implementation first, etc.).
